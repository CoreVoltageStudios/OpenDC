OpenDC managed Cinepak RGB decoder

Cinepak.cs is a managed adaptation of FFmpeg n7.1 libavcodec/cinepak.c:
https://github.com/FFmpeg/FFmpeg/blob/n7.1/libavcodec/cinepak.c

Changes: managed RGB-only decoder, explicit bounds, no FFmpeg framework or native
binary dependency, no Sega/palettized-video support. AVI demux, PCM conversion and
ODCV2 indexed writer are OpenDC code. No FFmpeg executable or development GPL build
is included. Source for the modified library is in viewer/DarkColony.Media; build
with dotnet build -c Release. It is a separate replaceable .NET assembly.

Any future public engine distribution must include this notice/license and complete
