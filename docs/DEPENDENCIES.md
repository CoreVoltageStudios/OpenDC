# Dependencies and bootstrap assets

Build: Godot 4.7.2 .NET SDK/editor/templates, .NET SDK (net8.0 target), Git and
PowerShell. Installer audit: Python3 standard library. Installer compiler:
Inno Setup7.1.1. Neither compiler nor development tools are part of the player payload.

- Godot/GodotSharp: MIT plus bundled component terms. `packaging/GODOT-COPYRIGHT.txt`
  and `GODOT-LICENSE.txt`; export also queries the actual template's license list.
- Self-contained .NET8: MIT and third-party terms, copied from the exact runtime
  pack used by the export. No separately installed player runtime is required.
- `viewer/DarkColony.Media`: LGPL-2.1-or-later adaptation of FFmpeg n7.1 Cinepak.
  Its NOTICE and COPYING accompany source and export. The DLL remains replaceable;
  export includes corresponding source and build/replacement instructions. No
  development FFmpeg binary is included or required by the importer.
- Barlow, Barlow Semi Condensed, Share Tech Mono, Red Hat Display: SIL OFL1.1.
  `viewer/DarkColony.Viewer/Fonts/provenance.json` pins each original URL/hash;
  adjacent OFL files preserve author and license text.

Bootstrap assets are separate from imported original content:
- Core Voltage Studios: original procedural Godot drawing and deterministic
  synthesized audio. Generator `tools/prepare_core_voltage_intro_audio.py`.
- Landfall wordmark: approved supplied vector design. Five synthesized cues are
  generated by `tools/prepare_restoration_audio.py`. These optional regeneration
  tools use NumPy; checked-in WAVs mean neither Python nor NumPy is needed to play.
- Application icon: approved original vector-derived Dark Side design. Its source
  asset note states no external art is embedded and the original game logo was
  neither embedded nor traced. The exact ICO and512px PNG are included.

Dennis Nilsson is named for his original material; Core Voltage Studios is the
studio credit. Original engine/importer/reusable UI code is MIT. The five approved
cues are CC BY 4.0. Original presentation/branding has source-fork, private-build
and private-run permission in [ASSET-LICENSES.md](../ASSET-LICENSES.md).
The [file/symbol map](PRESENTATION-LICENSE-MAP.md) distinguishes mixed files without
reserving reusable machinery. Public builds retaining reserved presentation need
separate permission. The adapted Cinepak library and other third-party material
retain their own terms. Provenance records grant no rights to original game content.

Original game tables, artwork, sound, music and movies are supplied by the player.
`content-contract.json` and `council-native-map.json` contain identification hashes,
filenames and extraction addresses/lengths, not extracted native payloads. Import
reads validated executables as data without executing them. The Human9 correction
is narrow, versioned and hash-checked; originals remain unchanged.

Version identities stay separate: app1.0.0-rc.1, Windows1.0.0.1, content contract1,
save and network protocol identities defined by the unchanged engine. A new source
commit changes build metadata; it must not be described as byte-identical to a prior
binary solely because gameplay source matches.
