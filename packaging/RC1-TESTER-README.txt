OpenDC 1.0.0 RC1 - local Windows x64 candidate
Core Voltage Studios

Unsigned candidate. Verify SHA256SUMS.txt. Do not bypass Windows security controls.
This is engine-only: no Dark Colony or Council Wars proprietary content is bundled.
Supply a legally obtained compatible English-EU source. Council Wars is optional.
Supported image/data routes and warnings are shown by the importer. A data-only ISO
has no CD music; original voices and effects still work. PP.AVI and Human training
lesson6 result-text fallbacks remain documented. No original EXE is executed.

1. Run Setup. Default is per-user %LOCALAPPDATA%\Programs\OpenDC, no administrator
   access required. Start-menu shortcut is created; desktop shortcut is optional.
2. Launch OpenDC. Follow Core Voltage Studios -> import -> restoration -> menu.
   Confirm a content destination outside the installation. Allow at least7GiB free.
3. Play a base mission or training lesson with God mode off. Save, change settings,
   exit and relaunch through the shortcut. Confirm Continue/load/settings.
4. Remove only a disposable source copy/unmount test media; relaunch without it.
   Add Council Wars later under Options > Game content. Verify a base save survives.
5. On a second computer with the SAME build and compatible own imported content,
   host/join by LAN IPv4, UDP27960. Separately test Hamachi using its IPv4. OpenDC
   never changes firewall/router rules. Allow private-network access if prompted.
   Ready/start, produce/move/fight, host pause/resume, client leave and AI takeover.
   Host leave must end the session with a clear return path. Repeat abrupt loss and
   start a NEW session; in-progress reconnect/save/load/restart are unsupported.
6. Uninstall in Installed Apps. Saves/preferences/imported content remain. Reinstall
   and confirm the retained library/Continue. There is no destructive data-removal
   option and no automatic cleanup of the legacy private development release.

Player data: %LOCALAPPDATA%\OpenDarkColony
Default content: %LOCALAPPDATA%\OpenDarkColony\Content (or your chosen library).
Keep those compatibility folder names; branding is OpenDC. App files need no writes
during play. Never place source media or your library inside the application folder.

Comparison testing (advanced): /COMPARE=unique-lowercase-name selects a separate
installer identity, application suffix, shortcuts and Comparisons/name profile.
Select a separate library when testing import failure/repair. No progress is imported
automatically. /DIR may select a new empty folder; managed upgrades use the same ID.

Version: display1.0.0 RC1; SemVer1.0.0-rc.1; Windows1.0.0.1.
Future RCn uses fourth component n (1..65534); final1.0.0 uses65535. Subsequent
patch/minor versions increase the first three fields. Highest installed version is
retained as a small registry stamp to prevent downgrades, even after uninstall.
Same-version reinstallation/repair is supported. Candidate rebuilds require fresh
artifact folders/checksums; they are not silently substituted for earlier candidates.

Local verification does not establish clean-Windows, LAN/Hamachi or full campaign
acceptance. Existing gameplay/performance/physical scrolling gaps and Relay polish
remain. Report build/hash, Windows/GPU, source edition and exact reproduction.
Public redistribution of this build requires separate permission for reserved
presentation. MIT engine, CC BY cue and third-party rights remain unchanged.
